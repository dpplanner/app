DPlanner 개인정보처리방침

시행일: 2026년 10월 10일 · 이전 버전 시행일: 2024년 6월 6일

DPlanner(이하 "서비스")는 「개인정보 보호법」에 따라 이용자의 개인정보를 보호하고, 관련 고충을 신속하게 처리하기 위해 다음과 같이 개인정보처리방침을 공개합니다.

1. 처리하는 개인정보 항목과 수집 방법

구분항목수집 방법
회원 가입·로그인이메일, 이름카카오·네이버·구글·애플 로그인 시 해당 서비스에서 제공받음
서비스 이용프로필 사진(선택), 클럽 내 이름·소개, 게시글·댓글·첨부 사진, 예약 정보, 반납 사진·메시지이용자가 직접 입력·업로드
알림푸시 알림 토큰모바일 앱 실행 시 자동 수집
자동 생성서비스 이용 기록, 접속 로그, 오류 기록서비스 이용 과정에서 자동 생성

서비스는 광고를 게재하지 않으며, 광고 식별자와 맞춤형 광고를 위한 행태정보를 수집하지 않습니다.

2. 개인정보의 처리 목적

  • 회원 식별, 로그인 유지, 부정 이용 방지
  • 클럽 가입·관리, 공간·물품 예약과 승인, 게시판·댓글 등 서비스 기능 제공
  • 예약·게시글 관련 푸시 알림 발송
  • 문의 응대, 오류 확인과 서비스 안정성 유지

3. 보유 및 이용 기간

  • 개인정보는 회원 탈퇴 시까지 보유·이용합니다.
  • 회원 탈퇴 시 클럽에 표시되는 이름·소개·프로필 사진은 즉시 "(탈퇴한 회원)"으로 변경됩니다.
  • 계정 정보(이메일·이름)는 부정 이용 방지를 위해 탈퇴 후 30일간 보관한 뒤 파기합니다.
  • 관계 법령에 따라 보존할 필요가 있는 경우 해당 기간 동안 보관합니다.

4. 개인정보 처리 위탁 및 국외 이전

서비스 운영을 위해 아래 업체에 개인정보 처리를 위탁하고 있습니다.

수탁자위탁 업무처리 국가
Oracle (Oracle Cloud Infrastructure)서버 운영, 데이터베이스 보관대한민국(춘천 리전)
Amazon Web Services (Amazon S3)사진 파일 보관대한민국(서울 리전)
Google (Firebase Cloud Messaging)푸시 알림 발송미국 등
Functional Software (Sentry)서비스 오류 기록·분석미국
Vercel웹 버전 호스팅미국 등

국외 이전 항목·시기·방법: 서비스 이용 시 네트워크를 통해 전송되며, 위 위탁 업무 수행에 필요한 범위로 한정됩니다.

서비스는 이용자의 개인정보를 위 위탁 외에 제3자에게 제공하지 않습니다. 단, 법령에 근거가 있는 경우는 예외로 합니다.

5. 개인정보의 파기 절차와 방법

보유 기간이 지나거나 처리 목적이 달성된 개인정보는 지체 없이 파기합니다. 전자적 파일은 복구할 수 없는 방법으로 삭제합니다.

6. 이용자의 권리와 행사 방법

  • 이용자는 언제든지 자신의 개인정보 열람·정정·삭제·처리 정지를 요구할 수 있습니다.
  • 앱의 설정 → 회원 탈퇴에서 직접 탈퇴할 수 있습니다.
  • 그 밖의 요청은 아래 연락처로 이메일을 보내 주시면 지체 없이 처리합니다. 앱 없이 계정 삭제를 요청하는 방법은 계정 삭제 안내를 참고해 주세요.

7. 자동 수집 장치

서비스는 쿠키를 사용하지 않습니다. 웹 버전은 로그인 유지를 위해 브라우저 저장소에 인증 토큰을 저장하며, 로그아웃하거나 브라우저 데이터를 삭제하면 지워집니다.

8. 개인정보의 안전성 확보 조치

  • 모든 통신 구간 HTTPS 암호화
  • 데이터베이스 접근을 허용된 서버 IP로 제한
  • 저장소 접근 권한을 필요한 범위로 최소화
